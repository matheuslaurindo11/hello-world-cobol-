# Hello World em COBOL

Meu primeiro programa escrito em **COBOL**, criado durante meus estudos da linguagem.

## Sobre

Um programa simples que exibe uma mensagem de **Hello World** no terminal.

## Tecnologias

* COBOL
* GnuCOBOL

## Executando

Compile o programa com:

```bash
cobc -x Helloword.cbl -o Helloword
```

Depois execute:

```bash
./Helloword
```

## Objetivo

Projeto criado para aprender os conceitos básicos de COBOL e praticar o uso da linguagem no Linux.
